Exam 1

Exam 1Area Between Curves

Problem 1

Consider \(f(x)=4x^2\) and \(g(x)=x^2+12\). Find the area between these curves.
Intersections: \(4x^2=x^2+12\Rightarrow 3x^2=12\Rightarrow x=\pm2\). Since \(g(x)\ge f(x)\) on \([-2,2]\), \[A=\int_{-2}^{2}\big[(x^2+12)-4x^2\big]dx=\int_{-2}^{2}(12-3x^2)dx=32.\]
Exam 1Square Cross Sections

Problem 2

Set up, but do not evaluate, the volume integral for the base enclosed by \(f(x)=-2x\) and \(g(x)=x^2\), with square cross sections perpendicular to the x-axis.
Intersections: \(x^2=-2x\Rightarrow x(x+2)=0\Rightarrow x=-2,0\). Top minus bottom is \((-2x)-x^2\). Square side length is \((-2x-x^2)\), so \[V=\int_{-2}^{0}(-2x-x^2)^2\,dx.\]
Exam 1Volumes of Revolution

Problem 3

Region between \(y=\sqrt{x}\), \(y=0\), and \(x=16\). Rotate about the y-axis. Set up washer and shell integrals. Then rotate about \(x=-2\).
For washers about the y-axis, use \(x=y^2\), \(0\le y\le4\): \[V=\pi\int_0^4\left(16^2-(y^2)^2\right)dy=\pi\int_0^4(256-y^4)dy.\] For shells about the y-axis: \[V=2\pi\int_0^{16}x\sqrt{x}\,dx.\] About \(x=-2\), using shells: radius \(x+2\), height \(\sqrt{x}\), so \[V=2\pi\int_0^{16}(x+2)\sqrt{x}\,dx.\]
Exam 1Work

Problem 4

A 30 m cable with mass 150 kg hangs from the top of a 90 m building. (a) Compute work to lift the cable. (b) Add a 100 kg beam at the bottom and compute combined work.
Cable density: \(150/30=5\text{ kg/m}\). Weight density: \(5(9.8)=49\text{ N/m}\). Let \(x\) be distance below the top, \(0\le x\le30\). Each piece is lifted \(x\) meters. \[W_{cable}=\int_0^{30}49x\,dx=49\frac{30^2}{2}=22050\text{ J}.\] Beam weight is \(100(9.8)=980\text{ N}\), lifted 30 m: \[W_{beam}=980(30)=29400\text{ J}.\] Combined: \[W=22050+29400=51450\text{ J}.\]
Exam 1Inverse Function

Problem 5

Let \(f(x)=x^3-8\). Compute \(f^{-1}(x)\), then compute \(\frac{d}{dx}f^{-1}(x)\).
Set \(y=x^3-8\). Swap variables: \(x=y^3-8\). Then \(y=\sqrt[3]{x+8}\). So \[f^{-1}(x)=(x+8)^{1/3}.\] Therefore \[\frac{d}{dx}f^{-1}(x)=\frac{1}{3}(x+8)^{-2/3}=\frac{1}{3\sqrt[3]{(x+8)^2}}.\]
Exam 1Second Derivative

Problem 6

Find \(f''(x)\) for \(f(x)=e^{\sin x}\).
\[f'(x)=e^{\sin x}\cos x.\] Product rule: \[f''(x)=e^{\sin x}\cos^2x-e^{\sin x}\sin x=e^{\sin x}(\cos^2x-\sin x).\]
Exam 1Tangent Line

Problem 7

Find the tangent line to \(f(x)=e^{2x}\) at \(x=3\).
\[f(3)=e^6,\qquad f'(x)=2e^{2x},\qquad f'(3)=2e^6.\] Tangent line: \[y-e^6=2e^6(x-3).\]
Exam 1Basic Integration

Problem 8

Calculate: (a) \(\int(e^{-4x}+5x^2+\sqrt{x})dx\), (b) \(\int 2x^4e^{x^5}dx\).
a) \[\int(e^{-4x}+5x^2+x^{1/2})dx=-\frac14e^{-4x}+\frac53x^3+\frac23x^{3/2}+C.\] b) Let \(u=x^5\), \(du=5x^4dx\). Then \[\int2x^4e^{x^5}dx=\frac25e^{x^5}+C.\]

Exam 2Derivatives

Problem 1

Compute \(dy/dx\): a) \(y=3^x\), b) \(y=\ln(x^2+5x)+\sin^{-1}x\), c) \(y=x^2+\tan^{-1}(6x)\), d) \(y=x^{\cos x}\).
a) \(y'=3^x\ln3\).
b) \[y'=\frac{2x+5}{x^2+5x}+\frac{1}{\sqrt{1-x^2}}.\]
c) \[y'=2x+\frac{6}{1+36x^2}.\]
d) Log differentiate: \(\ln y=\cos x\ln x\). Then \[y'=x^{\cos x}\left(-\sin x\ln x+\frac{\cos x}{x}\right).\]
Exam 2Limits

Problem 2

Compute: a) \(\lim_{x\to0}\frac{2-2\cos(5x)}{3x^2+x-\sin x}\). b) Find \(A\) so L'Hospital applies to \(\lim_{x\to3}\frac{x^2-2x+A}{2x-6}=L\), then compute \(L\).
a) Apply L'Hospital twice: first gives \(\frac{10\sin5x}{6x+1-\cos x}\), still \(0/0\). Second gives \[\lim_{x\to0}\frac{50\cos5x}{6+\sin x}=\frac{50}{6}=\frac{25}{3}.\] b) Need numerator \(=0\) at \(x=3\): \(9-6+A=0\Rightarrow A=-3\). Then \[L=\lim_{x\to3}\frac{2x-2}{2}=\frac{4}{2}=2.\]
Exam 2Inverse Trig Values

Problem 3

Compute: a) \(\sin(\arcsin1)\), b) \(\arcsin(\sin\pi)\), c) \(\arctan(\cos0)\), d) \(\arcsin(\cos(-\pi/6))\), e) \(\arcsin(\cos(\pi/2))\).
a) \(1\). b) \(\arcsin(0)=0\). c) \(\arctan(1)=\pi/4\). d) \(\cos(-\pi/6)=\sqrt3/2\), so \(\arcsin(\sqrt3/2)=\pi/3\). e) \(\cos(\pi/2)=0\), so \(\arcsin(0)=0\).
Exam 2Triangle Identity

Problem 4

Complete the identity using the triangle method: \(\cos(\tan^{-1}(3x))\).
Let \(\theta=\tan^{-1}(3x)\). Then \(\tan\theta=3x/1\). Opposite \(=3x\), adjacent \(=1\), hypotenuse \(=\sqrt{1+9x^2}\). Therefore \[\cos(\tan^{-1}(3x))=\frac{1}{\sqrt{1+9x^2}}.\]
Exam 2Integration by Parts

Problem 5

Evaluate \(\int x^2e^{3x}dx\).
Using integration by parts twice: \[\int x^2e^{3x}dx=e^{3x}\left(\frac{x^2}{3}-\frac{2x}{9}+\frac{2}{27}\right)+C.\]
Exam 2Trig Integral

Problem 6

Evaluate \(\int \sec^4(x)\tan^3(x)dx\).
Write \(\sec^4x\tan^3x=\sec^2x\tan^3x\sec^2x\). Let \(u=\tan x\), \(du=\sec^2x dx\), and \(\sec^2x=1+\tan^2x=1+u^2\). \[\int u^3(1+u^2)du=\frac{u^4}{4}+\frac{u^6}{6}+C=\frac{\tan^4x}{4}+\frac{\tan^6x}{6}+C.\]
Exam 2Trig Substitution

Problem 7

Evaluate \(\int\frac{1}{\sqrt{x^2+9}}dx\).
Standard form: \[\int\frac{dx}{\sqrt{x^2+a^2}}=\ln\left|x+\sqrt{x^2+a^2}\right|+C.\] With \(a=3\): \[\int\frac{dx}{\sqrt{x^2+9}}=\ln\left|x+\sqrt{x^2+9}\right|+C.\]
Exam 2Partial Fractions

Problem 8

Evaluate \(\int\frac{5x^2-3x+3}{x(x^2+1)}dx\).
Decompose: \[\frac{5x^2-3x+3}{x(x^2+1)}=\frac{A}{x}+\frac{Bx+C}{x^2+1}.\] Then \(A=3\), \(B=2\), \(C=-3\). So \[\int\left(\frac3x+\frac{2x-3}{x^2+1}\right)dx=3\ln|x|+\ln(x^2+1)-3\tan^{-1}x+C.\]
Exam 2Improper Integral

Problem 9

Determine whether \(\int_0^\infty 4e^{-3x}dx\) converges or diverges. If it converges, find the value.
\[\int_0^\infty4e^{-3x}dx=\lim_{b\to\infty}\left[-\frac43e^{-3x}\right]_0^b=0-\left(-\frac43\right)=\frac43.\] It converges to \(\frac43\).

Exam 3Arc Length & Surface Area

Problem 1

Let \(f(x)=e^{\sin x}\). (a) Set up arc length on \([2,5]\). (b) Set up surface area about the x-axis on \([2,5]\). Do not compute.
\[f'(x)=e^{\sin x}\cos x.\] Arc length: \[L=\int_2^5\sqrt{1+\left(e^{\sin x}\cos x\right)^2}\,dx.\] Surface area about the x-axis: \[S=2\pi\int_2^5e^{\sin x}\sqrt{1+\left(e^{\sin x}\cos x\right)^2}\,dx.\]
Exam 3Taylor Polynomial

Problem 2

Find the third-degree Taylor polynomial for \(f(x)=\cos x\) centered at \(x=\pi/6\).
Let \(a=\pi/6\). Values: \(f(a)=\sqrt3/2\), \(f'(a)=-1/2\), \(f''(a)=-\sqrt3/2\), \(f'''(a)=1/2\). \[T_3(x)=\frac{\sqrt3}{2}-\frac12\left(x-\frac\pi6\right)-\frac{\sqrt3}{4}\left(x-\frac\pi6\right)^2+\frac{1}{12}\left(x-\frac\pi6\right)^3.\]
Exam 3Sequences & Geometric Series

Problem 3

a) Determine whether \(a_n=\frac{(n+1)^n}{(3n)^n}\) converges or diverges. b) Explain why \(3+\frac92+\frac{27}{4}+\frac{81}{8}+\cdots\) diverges.
a) \[a_n=\left(\frac{n+1}{3n}\right)^n=\left(\frac{1+1/n}{3}\right)^n=\left(1+\frac1n\right)^n\left(\frac13\right)^n\to e\cdot0=0.\] The sequence converges to \(0\).
b) This is geometric with first term \(a=3\) and ratio \(r=\frac32\). Since \(|r|>1\), the series diverges.
Exam 3Alternating Series

Problem 4

Determine whether \(\sum_{n=1}^{\infty}\frac{(-1)^n n}{n^3+9}\) converges or diverges.
Consider absolute value: \[\sum\frac{n}{n^3+9}.\] For large \(n\), this behaves like \(\sum\frac{1}{n^2}\), which converges. By limit comparison with \(1/n^2\): \[\lim_{n\to\infty}\frac{n/(n^3+9)}{1/n^2}=\lim_{n\to\infty}\frac{n^3}{n^3+9}=1.\] Therefore the original series converges absolutely.
Exam 3Limit Comparison

Problem 5

Determine whether \(\sum_{n=1}^{\infty}\frac{3n^2+2n+1}{2n^4+5n+6}\) converges or diverges.
Dominant terms give \(\frac{3n^2}{2n^4}=\frac{3}{2n^2}\). Use limit comparison with \(1/n^2\): \[\lim_{n\to\infty}\frac{(3n^2+2n+1)/(2n^4+5n+6)}{1/n^2}=\lim_{n\to\infty}\frac{3n^4+2n^3+n^2}{2n^4+5n+6}=\frac32.\] Since \(\sum1/n^2\) converges, the given series converges.
Exam 3Ratio Test

Problem 6

Determine whether \(\sum_{n=1}^{\infty}\frac{2^n n^n}{3^n n!}\) converges or diverges.
Let \(a_n=\frac{2^n n^n}{3^n n!}\). Ratio test: \[\frac{a_{n+1}}{a_n}=\frac{2}{3}\cdot\frac{(n+1)^{n+1}}{n^n}\cdot\frac{n!}{(n+1)!}=\frac{2}{3}\left(\frac{n+1}{n}\right)^n.\] Therefore \[L=\frac23\lim_{n\to\infty}\left(1+\frac1n\right)^n=\frac{2e}{3}>1.\] The series diverges.
Exam 3Comparison Test

Problem 7

Determine whether \(\sum_{n=1}^{\infty}\frac{\sin^2(n)+4}{n}\) converges or diverges.
Since \(\sin^2(n)\ge0\), \(\sin^2(n)+4\ge4\). Thus \[\frac{\sin^2(n)+4}{n}\ge\frac4n.\] Since \(\sum\frac4n\) diverges, the given series diverges by comparison.
