Exam 1 Quick Reference

6.1 Area Between Curves

  • \(\displaystyle A=\int_a^b (\text{top} - \text{bottom})\,dx\)
  • \(\displaystyle A=\int_c^d (\text{right} - \text{left})\,dy\)

6.2 Average Value

  • \(\displaystyle f_{\text{avg}}=\frac{1}{b-a}\int_a^b f(x)\,dx\)

6.3 Volumes of Revolution

  • \(\displaystyle V=\pi\int_a^b R(x)^2\,dx\) (disk)
  • \(\displaystyle V=\pi\int_a^b \big(R(x)^2-r(x)^2\big)\,dx\) (washer)

6.4 Cylindrical Shells

  • \(\displaystyle V=2\pi\int_a^b (\text{radius})(\text{height})\,dx\)
  • \(\displaystyle V=2\pi\int_c^d (\text{radius})(\text{height})\,dy\)

6.5 Work

  • \(\displaystyle W=\int_a^b F(x)\,dx\)
  • For fluids: use a thin slice, then distance \(\times\) weight density \(\times\) volume slice

7.1 Exponential Functions

  • \(\displaystyle \frac{d}{dx}(e^x)=e^x\)
  • \(\displaystyle \frac{d}{dx}(a^x)=a^x\ln a\)
  • \(\displaystyle \int e^x\,dx=e^x+C\)
  • \(\displaystyle \int a^x\,dx=\frac{a^x}{\ln a}+C\)

7.2 Inverse Functions

  • \(\displaystyle (f^{-1})'(a)=\frac{1}{f'(f^{-1}(a))}\)
  • \(\displaystyle \frac{d}{dx}\ln x=\frac{1}{x}\)
  • \(\displaystyle \frac{d}{dx}\log_a x=\frac{1}{x\ln a}\)
